# 🎒 Knapsack Problem - Interactive Learning Website

An interactive educational website that brings the **Knapsack Problem** to life through visual demonstrations, algorithm simulations, and engaging problem-solving activities.

The platform helps students understand optimization techniques by exploring how different algorithms select items to maximize value while staying within a given weight capacity.

## 🌐 Overview

The Knapsack Problem is a classic combinatorial optimization problem in computer science. This website transforms the theoretical concept into an interactive learning experience where users can experiment with different inputs, visualize algorithms, and test their understanding.

Instead of learning through formulas alone, users can explore the problem through practical examples and real-time simulations.

## ✨ Features

### 1. Interactive Learning
- Understand the fundamentals of the Knapsack Problem.
- Explore 0/1 and Fractional Knapsack.
- Learn through visual explanations and examples.

### 2. Knapsack Simulator
- Add, edit, and remove items.
- Set custom item weights and values.
- Adjust the maximum backpack capacity.
- Calculate the optimal combination using Dynamic Programming.
- Compare manual selection, Greedy selection, and the optimal solution.

### 3. Dynamic Programming Visualizer
- Understand the Dynamic Programming approach step by step.
- Explore the recurrence relation.
- Visualize the DP table.
- Watch the algorithm calculate values through animations.
- Navigate through individual calculation steps.

### 4. Algorithm Comparison
Explore and compare:
- Brute Force
- Greedy Algorithm
- Dynamic Programming
- Branch and Bound

Understand their working principles, advantages, limitations, and time complexities.

### 5. Real-World Applications

Discover how the Knapsack Problem is used in:

- Finance and portfolio selection.
- Logistics and transportation.
- Computing and memory allocation.
- Business and resource management.
- Everyday packing and planning.

### 6. Interactive Challenge
- Participate in a virtual bag-packing challenge.
- Select items within a limited capacity.
- Compare your selection with the optimal solution.
- Receive scores and performance feedback.

### 7. Knowledge Check
- Test your understanding through multiple-choice questions.
- Get instant feedback and explanations.
- Track your score.
- Retry the quiz to improve your performance.
